# 素材取り出しスクリプト（参考）

提出用フォーマット（.ai）から `src/assets/` の素材を作ったときのスクリプトです。
作業時の一時フォルダのパスがそのまま書かれているので、再利用するときはパスを直してください。

- `grp.py` … レイヤー内のグループを1つずつ描いて一覧画像にする（どれが何かを調べる用）
- `sealblocks.py` / `blocks.json` / `b12.json` … ネックシールレイヤーを色違いごとのまとまりに分けた結果
- `common.py` … レイヤー範囲の定義と、部品だけを描くレンダリング関数
- `step1.py` / `step2.py` … 下地・透過マップ・部品画像のレンダリング
- `export.py` … 書き出した素材を `src/assets/` 用に切り出して保存

必要なもの：`pip install pikepdf pypdfium2 numpy pillow`
