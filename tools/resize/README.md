# 横長リサイズ（管理サイトの「リサイズ候補」）

Asana の「リサイズ」依頼を定期実行の Claude が拾って管理サイトの「リサイズ候補」に載せ、スタッフが「📐 リサイズする」を押したものを作って一覧に登録する仕組み。

1. `candidates.py add` … Asana の依頼から候補を登録（添付写真とサムネを管理サイトのドライブへ）
2. 管理サイトで「リサイズする」→ 状態がリサイズ依頼になる
3. `candidates.py queue` / `src` … 依頼された候補と元画像を取る
4. `place.py` … 大事な範囲（頭、または顔・文字・ロゴ）をフォーマットの白い範囲に入れる位置を計算し、生成拡張の入力と広げる量を作る
5. Adobe の生成拡張（image_generative_expand）で背景を広げる
6. `finish.py` … 元の画素を重ね直して 2880×2048 のデザイン画像と確認用画像を作る
7. `compose.py` … 提出用フォーマット（index.html）で提出用 JPG・タグ画像を作る
8. `register.py` … 管理サイトに登録し、候補を作成済みにする

フォーマット：仕上がり 1440×1024px。上の帯 0〜254px・下の帯 917〜1024px に顔や重要なデザインを入れない。左右 0〜134px・1306〜1440px は背面（背景のみ）。
管理サイトの URL と登録用キーは環境変数 `ORISHAN_URL`・`ORISHAN_KEY` で渡す（ここには書かない）。
