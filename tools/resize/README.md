# 横長リサイズ（管理サイトの「リサイズ候補」）

Asana の「リサイズ」依頼を定期実行の Claude が拾って管理サイトの「リサイズ候補」に載せ、スタッフが「📐 リサイズする」を押したものを作って一覧に登録する仕組み。

1. `candidates.py add` … Asana の依頼から候補を登録（添付写真とサムネを管理サイトのドライブへ）
2. 管理サイトで「リサイズする」→ 状態がリサイズ依頼になる
3. `candidates.py queue` / `src` … 依頼された候補と元画像を取る
4. `place.py` … 大事な範囲（頭、または顔・文字・ロゴ）をフォーマットの白い範囲に入れる位置を計算し、生成拡張の入力と広げる量を作る
5. Adobe の生成拡張（image_generative_expand）で背景を広げる。**一度に広げず、3回に分けて少しずつ**（1回で大きく広げると、元にない形〈丸い布・額縁など〉をAIが作ってしまう）。元の背景の柄・色・質感がそのまま続いているかを毎回見る
6. `finish.py` … 元の画素を重ね直して（ふち80pxでなじませる）、左右の端を背面でつなぎ（巻いたときに途切れない）、2880×2048 のデザイン画像と確認用画像を作る
7. `compose.py` … 提出用フォーマット（index.html）で提出用 JPG・タグ画像を作る
8. `register.py` … 管理サイトに登録し、候補を作成済みにする

フォーマット：仕上がり 1440×1024px。上の帯 0〜254px・下の帯 917〜1024px に顔や重要なデザインを入れない。左右 0〜134px・1306〜1440px は背面（背景のみ）。
管理サイトの URL と登録用キーは環境変数 `ORISHAN_URL`・`ORISHAN_KEY` で渡す（ここには書かない）。

## 修正依頼（管理サイトの「🔧 修正を依頼」）
リサイズの案件（テンプレ＝リサイズ）の修正依頼は Decolino 側には出ず、`candidates.py fixes` でだけ取れる。
1. `candidates.py fixstate <一覧のID> "生成中|<今のミリ秒>|"` → `candidates.py fixsrc <一覧のID> DIR/src.jpg`（その案件を作った元画像）
2. 修正内容に合わせて `place.py`（`--pos` `--zoom` `--dx` `--dy`）→ 生成拡張（3回に分けて）→ `finish.py` → `compose.py`（仕様の変更があれば spec を変える）
3. `register.py ... --fix "<修正内容>"`（同じ注文・名前で登録 → 版が上がり、修正前は履歴に残り、修正指示が消えて「修正済み」になる）
4. 失敗したら `candidates.py fixstate <一覧のID> "エラー:<理由>"`

## 文字入れ（文字例3案）
- 候補の「文字」（管理サイトの「文字入れ（任意）」欄）に文言があると、リサイズ後に `textopts.py DIR --cand ID --text '…' --styles a,b,c` で文字例を3案作って送る → 候補は「文字案選択」。
- 画面で「案○にする」を押すと「文字案決定」→ 次の定期チェックで `candidates.py chosen ID DIR/design.jpg` → `compose.py` → `register.py`。
- 文字は書体で描く（`textlayer.py`、AIに描かせない）。位置の基本は人物の下（白い範囲の下端）。飾り方は pirate（海賊風）・script（筆記体）・pop（ポップ）・gold（ゴールド）・elegant（エレガント）から背景に合う3つ。
- 書体は `fonts/`（@fontsource、OFL）。

## リサイズ不要の見分け
- `ready.py SRC --out DIR`：すでに横長1440×1024と同じ比率（±2%）で横幅1440px以上なら「リサイズ不要」。背景は広げず 2880×2048 にそろえた DIR/design.jpg を作る → （文字入れ）→ compose → register（メモに「リサイズ不要」）。
- 候補を拾うとき（candidates.py add）も同じ判定で、説明の先頭に【リサイズ不要：…】を付け、押さなくても自動で「リサイズ依頼」にする（同じ定期実行のBで提出用まで作る）。

## 全自動
- Asanaから拾った候補は、登録と同時に「リサイズ依頼」になる（管理サイトで選ばなくてよい）。同じ定期実行のBで期日が近い順に作る（1回最大3件、残りは次の回）。
- 作りたくないものは、管理サイトのカードの「依頼をやめる」「対象外にする」で止められる（作成中になる前）。
- 文字案は提出用フォーマットまで3案作る（`textopts.py … --spec '<spec>' --checks '<checks>'`、DIR/opt1〜3/）。画面で「案○にする」を押すと、その場で一覧に登録される（定期実行を待たない）。
- 手動の依頼で Asana の URL があれば、店名・名前・期日・注文は空欄でよい（定期実行が Asana から埋める）。
- Asanaの依頼に文字入れの指定（「文字入れ：Happy Birthday」「〇〇と入れてください」など）があれば、候補の「文字」に入れて登録する（ITEMS.json の "text"）。リサイズのあと自動で文字案を提出用まで3案作る。

## 書体（20種類）
- `python3 textlayer.py --list` で一覧（名前・合う背景の目安）。英字14種類＋日本語も書ける6種類（和ポップ・筆文字・和モダン・丸ゴシック・手書きかわいい・極太）。
- 書体は @fontsource（OFL）。英字の古い5種類は fonts/ にあり、それ以外は使うときに npm から取って fonts/pkg/ にためる（git には入れない）。日本語は文字に必要な分だけ読み込む。
- 文字と下の背景の明るさが近いと、自動で縁に影（暗い背景なら光）を足して読みやすくする。
- 文字は依頼のまま変えない（大文字にする・「!」を足すなどもしない）。全部大文字に見える書体（ポップ・ゴールド・コミック・ストリート）は、文言が大文字だけのときしか使わない。

## 人物の大きさ
- 標準で頭の高さを 605px（仕上がり）にした（2026-10-29、432pxの1.4倍。頭の上端は270pxのまま）。文字も標準で1.4倍（1行の幅 2520px、作業座標。白い範囲からはみ出す・顔に重なるときは自動で縮める）。Decolinoで作る案件も、人物と名前の文字を大きめ（1.4倍）にするよう要望に入れる。
- 管理サイトの「人物の大きさ」（手動依頼の画面・候補カード）：小さめ0.87／標準／大きめ1.15／特大1.3倍 → `place.py --size <大きさ>`。頭の上端は動かさず下に向かって大きくなる。
- できあがったカードの「👤 人物を大きく」「👤 人物を小さく」で、ひと回り（約15%）大きく／小さくする修正依頼が入る。

## 裏の文字（Asanaの「裏：〇〇」）
- 裏の文字はデザインの表には入れず、提出用フォーマットの「ロゴを裏に入れる」の位置に入れる（`compose.py --back '<文字>' [--back-opt '<JSON>']`、`textopts.py`・`register.py` も同じ引数）。
- 文字は一字も変えない。「|」で改行。
- `--back-opt`：`{"dir":"auto|v|h|r","font":"<書体キー>","color1":"#..","color2":"#..","stroke":"#.."}`。どれも省略できる。
  - dir：v＝縦書き（2行目以降は下揃え）、h＝横書き（いちばん大きく描ける文字数で自動で折り返す）、r＝横書きを90°回す、auto＝日本語は縦書き・英数字は90°。依頼に「横書き」とあれば h。
  - font：提出用ツールの `BACKFONTS`（mincho 明朝／gothic ゴシック／zenantique 和モダン／yuji 筆／dela 極太／zenmaru 丸ゴシック／mochiy ポップ／hachimaru 手書き風／playfair 上品／vibes・dancing 筆記体／cinzel 大文字だけ／lobster／pacifico／caveat 手書き／pirata 海賊／fraktur ゴシック体／rye ウエスタン）。デザインの雰囲気に合うものを選ぶ。省くと日本語は明朝、英字は playfair。
  - 色：省くとデザインの色から自動（入れる場所が暗ければ明るい色、明るければ濃い色。色みはデザインでいちばん目立つ色）。指定するときは color1（上）・color2（下）・stroke（縁）。
- 大きさは自動でフォーマット内（1440換算で幅≦240px＝左右の帯134pxの内側、高さ≦600px・中心585px＝上下の帯にかからない）。
- compose.py は裏の文字入りのデザイン画像を `design_back.jpg` に書き、register.py はそれがあればデザイン画像として送る（仕様に back・backOpt が残る）。
- 書体は jsdelivr の @fontsource から読む。compose.py はそのリクエストを手元の npm パッケージ（fonts/pkg）で返す。
- 提出用ツール側：`await window.__setBackText(text, opt)`（入れる／空で外す）、`window.__designJpeg()`（文字入りのデザイン画像）。画面のステップ2「裏の文字」からも入れられる。
