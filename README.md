# ボトルラベル提出フォーマット

デザイン画像とロゴを入れると、オリジナルシャンパンの**提出用フォーマット**（A4・300dpi）に自動で差し込み、JPG・PDF・デザイン画像・タグ画像で保存できる Web ツールです。

- **公開URL**：https://kaeru045.github.io/bottle-label/
- Claude を持っていない人でも、パソコン・スマホのブラウザだけで使えます。
- 画像はブラウザの中だけで処理され、どこにも送信されません。
- 画面の説明文の後ろにある「ver ○○」で、表示中の版が分かります。

---

## 使い方

1. **デザイン画像**を入れる（クリック・ドラッグ・貼り付けのどれでも可）
2. 必要なら**ロゴ**を入れる（左右に分割して、ボトルの裏で1つにつながるように配置）
3. **仕様**を選ぶ（ネック色・ネックシール・デコ・リボン・タグ）
4. **書き出し**で保存する

### 画像の入れ方
| 方法 | やり方 |
|---|---|
| クリック／ドラッグ | 各画像の枠をクリックしてファイルを選ぶ、またはファイルをドラッグ |
| 貼り付け（パソコン） | 画像をコピーして、ページ上で Ctrl+V（Mac は ⌘+V）。ロゴやオリジナルネックシールに入れるときは、その枠にマウスを乗せてから貼り付け |
| 貼り付け（スマホ） | 枠の中の点線「ここを押して貼り付け」を長押し →「ペースト」、または「📋 貼り付け」ボタン |

### 保存されるファイル（ファイル名欄に「Kurumi」と入れた場合）
| ボタン | ファイル |
|---|---|
| 提出用 JPG を保存 | `Kurumi提出用.jpg`（2481×3508px） |
| 提出用 PDF を保存 | `Kurumi提出用.pdf`（A4） |
| デザイン画像を保存 | `Kurumiデザイン画像.jpg`（3307×2347px） |
| タグ画像だけ保存 | `Kurumiタグ_ハート型.png`・`Kurumiタグ_猫.png` など（タグの形で切り抜いた透過PNG） |
| まとめて保存 | `Kurumi提出用.jpg` と `Kurumiデザイン画像.jpg` の2枚 |

※ iPhone の Safari は1回に1枚しか保存できないことがあります。その場合は1つずつ保存してください。

## 機能一覧

### 1. デザイン画像
- 提出用フォーマットの「デザイン」枠・ボトル前後・タグに自動で差し込み
- 印刷用デザインは **3307×2347px（横1.41：縦1）** で書き出し
- **リサイズ用 ChatGPT プロンプト**を常に表示（「リサイズする場合は、このプロンプトをコピーして ChatGPT で生成してください」）。コピーボタン付き

### 2. ロゴ（左右に分割）
- ロゴを真ん中で2つに切り、右半分をデザインの左端、左半分を右端に配置 → ボトルに巻くと背面で1つのロゴになる
- 「ロゴを裏に入れる」チェック（**初期値はオフ**、ロゴを入れると自動でオン）
- 大きさ・上下位置・影の強さを調整、「ロゴをクリア」「標準の設定に戻す」

### 3. 仕様
| 項目 | 選択肢 |
|---|---|
| ネック色（キャップ） | ゴールド／シルバー／ブラック／ホワイト／Pピンク／ローズ／レッド／イエロー／グリーン／水色／ブルー／SPL青／パープル／Pパープル／ローズゴールド／好きな色 |
| ネックシール（Luxury） | ブラック／ホワイト／ゴールド／シルバー／グリーン（ユグドラ／リーヴス） |
| オリジナルネックシール | 入稿データ（前面のシール画像）をアップロード。背面は白無地 |
| デコ（ストーン） | ネック（ネックシールの下）／チラシ（ボトル全体） |
| リボン | なし／赤／ピンク／黄／水色／白／黒 |
| タグ | なし／スクエア／ハート型／猫／くま／月／ボトル型 |
| ボトル型タグのシール | ホワイト／ブラック／ピンク |
| タグ内の画像 | 左右・上下・大きさ（初期50%、10〜150%）、左右反転・上下反転・90°回転、「🔍 タグを拡大表示」 |
| タグの文字を切り離す | 大きな切り出し画面で文字を四角で囲み（あとから移動・大きさ変更可）、「背景の色を消す」か「文字の色を残す」で文字だけにする。消しゴム・戻すブラシ、小さなゴミの自動除去。タグ上で位置・大きさ・回転を調整。元の文字は周りの色で埋めて消す |

### 4. 書き出し
上の「保存されるファイル」を参照。

### プレビュー
- 右側（スマホは上）に固定表示。項目を選ぶとすぐ反映
- 「全体／デザイン／ボトル／タグ」で見たい部分を拡大

## 開発中の機能

- **タグの文字を切り離す**（文字の切り出し・消しゴム・タグ上での移動）… `#dev` のときだけ表示

- **手動リサイズ**（合わせ方・拡大・位置・安全範囲の確認・ぼかして延長）  
  URL の最後に `#dev` を付けたときだけ表示：https://kaeru045.github.io/bottle-label/#dev

- **横長リサイズ（1440×1024・人物写真）** … `#dev` のときだけ「デザイン画像」の欄に「🖼️ 横長リサイズを開く」が出る
  - フォーマット：上の帯 0〜254px・下の帯 917〜1024px には顔や重要なデザインを入れない。左右 0〜134px・1306〜1440px は背面（背景のみ）
  - 写真を入れて、点線の枠を頭（髪のてっぺん〜あご）に合わせると、頭の上端 270px・高さ 360px の位置に自動で置く（中央／左寄せ／右寄せ、人物の大きさ 70〜130%）
  - 頭が帯にかかると赤字で警告
  - 生成用画像（2880×2048、余白は白＝ChatGPT用／透明＝Photoshop用）とプロンプトを出す → ChatGPT・Photoshop で背景を描き足す
  - 生成した画像を戻すと、写真の部分の明るさで自動で位置合わせし、元の写真をふちをなじませて重ね直す（人物は元のピクセルのまま）
  - 保存名：`<名前>_横長_中央.png`（1440×1024）、`<名前>_生成用_中央_白.png`

## フォルダ構成

```
index.html            公開ページ（tools/build.py で自動生成。直接編集しない）
src/index.html        ツール本体（ここを編集する）
src/assets/           提出用フォーマットから取り出した素材画像
tools/build.py        src から公開用の index.html を作る
tools/vendor/         jsPDF・JSZip（ページに埋め込む）
tools/extract/        .ai から素材を取り出したときのスクリプト（参考）
CLAUDE.md             Claude 向けの開発メモ
```

## 更新のしかた

1. `src/index.html` を編集する
2. `python3 tools/build.py` を実行して `index.html` を作り直す
3. 画面の「ver ○○」を更新する
4. コミットして `main` に push → 数分で公開ページに反映
